## Why this is a pointer

`INTEGRATION_ARCHITECTURE.md` defines the provider-neutral integration model —
the registry, the source mapper, the trigger envelope dispatcher, the dispatch
ledger, completion ingest, the MCP gateway, and the shape each provider adapter
takes. Every Perception Engine implements it, so it has to say the same thing to
all of them.

It was forked. Three near-identical copies existed — `RealityEngine_CI/docs/`,
`RealityEngine_CPP/docs/` and `RealityEngine_LSP/docs/` — differing by roughly a
kilobyte each, and the differences were not editorial. This copy carried the
`carekit` integration kind and a CareKit adapter section that the master did not
have; the master carried the canonical Ollama model default and precedence rules
that this copy did not. Neither was a superset, so a reader could not have known
which to trust, and "the integration model" had no single answer.

That is the failure `SURFACE_SPEC.md` demonstrated in the other direction on
2026-08-27: kept as a canonical copy plus duplicates, two correct parallel edits
described one rule in different words and turned `main` red. Here the copies had
already diverged in content rather than wording, which is worse — nothing went
red at all.

Governance has one home. `RealityEngine_CI` holds `SURFACE_SPEC.md`,
`MACHINE_CONCEPT.md`, `ARBITER_ARCHITECTURE.md`, `DEPLOYMENT_CONTRACT.md`, the
`docs/*_CONTRACT.md` files and this; `scripts/check-surface-specs.sh` enforces
that each has exactly one master and that every pointer is still a pointer.

## What this repository still owns

Its implementation of the integration model, and the worked instances that
document what the master deliberately does not carry — the broker, bridge and
configuration detail:

- `docs/MQTT_YUMA_DEMONSTRATION.md` — MQTT, live against an external broker.
- `docs/CAREKIT_BRIDGE.md` — the CareKit device bridge, which is where the
  CareKit material from this file's forked copy now lives.
- `docs/HEALTHKIT_SPEZI_BRIDGE.md` — the HealthKit device bridge.

The rules those instances obey are one level up again, in
`RealityEngine_CI/docs/EXTERNAL_INTEGRATION_CONTRACT.md`.
